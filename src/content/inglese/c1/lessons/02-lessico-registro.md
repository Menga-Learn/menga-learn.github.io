## Lessico C1: precisione, registro e idiomi

Al C1 la differenza non la fa sapere *più parole*, ma scegliere **la parola precisa** per il contesto e il **registro**.

### Sinonimi non intercambiabili

| Parole | Sfumatura |
| --- | --- |
| *claim / state / argue* | *claim* suggerisce dubbio; *state* è neutro; *argue* sostiene con ragioni |
| *reluctant / unwilling* | *reluctant* = esitante ma potrebbe; *unwilling* = non vuole |
| *economic / economical* | *economic* = dell'economia; *economical* = che fa risparmiare |
| *sensible / sensitive* | *sensible* = ragionevole; *sensitive* = sensibile |
| *eventually / possibly* | *eventually* = alla fine (non "eventualmente"!) |

### Collocazioni avanzate

*pose a threat, raise awareness, meet a deadline, bear in mind, draw a conclusion, reach a consensus, address an issue, a sharp decline, a marked difference, a growing body of evidence, bitterly disappointed, highly unlikely, deeply concerned.*

### Registro

| Neutro/informale | Formale |
| --- | --- |
| find out | ascertain, establish |
| get better | improve |
| put up with | tolerate |
| ask for | request |
| look into | investigate |
| try | attempt, endeavour |
| enough | sufficient |
| need | require |

Nei testi formali si preferiscono **verbi latini singoli** ai phrasal verb; nel parlato informale vale l'opposto, e un registro troppo formale suona innaturale.

### Espressioni idiomatiche frequenti

- *a blessing in disguise* — un male che si rivela un bene
- *the tip of the iceberg* — la punta dell'iceberg
- *to cut corners* — fare le cose in fretta e male per risparmiare
- *to be on the same page* — essere d'accordo, allineati
- *to get to grips with* — imparare a gestire
- *to call it a day* — smettere per oggi

### Modali con sfumature

- ***needn't have** done*: l'ho fatto ma non era necessario. ≠ *didn't need to*: non era necessario (probabilmente non l'ho fatto).
- *You **might have** told me!* (rimprovero).
- *They **are bound to** win* (è quasi certo).
